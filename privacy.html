About the app

youtubeauto is a private, single-user tool operated by Yalçın Torun (Adana, Turkey). It uses YouTube API Services to upload and manage videos on the owner's own two YouTube channels only:

  • English channel: UCrdWZ6mx7dFDgULQ2Pk1sJg
  • Turkish channel: UCHBXvKJcamqvwrZS4OetCXw

By using YouTube API Services, this app is subject to the Google Privacy Policy.

Data accessed

The app accesses only video metadata (such as titles, descriptions, and video IDs) of the owner's own channels, through the owner's authorized Google account.

Data stored

The app stores only the owner's own video IDs and titles locally, solely for deduplication (avoiding duplicate uploads). No other data is stored.

Third-party user data

The app does not access, collect, or store any data of other YouTube users or third parties.

Data sharing

No data is shared with, sold to, or disclosed to any third party.

Revoking access

Access granted to this app can be revoked at any time via Google security settings: https://security.google.com/settings/security/permissions. Locally stored data can be deleted on request.
